If an install fails

A phone that reaches Fastboot Mode can be installed again. Find the case that fits and follow it. Back to the web installer.

Getting back to Fastboot Mode

  • Hold Power and Volume down until the phone restarts and shows Fastboot Mode.
  • If it starts Android or keeps restarting on the logo, hold both again.
  • Then press Connect on the installer page. Reload the page first if it shows an error about the USB device.

The phone stopped answering

  • The bootloader stops answering when a command is cut off while the phone replies. Only a restart frees it.
  • The installer never cuts a reply off. When the phone has not answered for a while, it asks for a restart and sends nothing more.
  • Hold Power and Volume down until the phone restarts into Fastboot Mode. Then press Connect and carry on.
  • Do not unplug the phone or close the page while a command runs.

It stopped before writing

  • A check failed: the phone, its lock state or a file of the image set.
  • Nothing on the phone changed. Fix what the message names and start again.
  • A file that does not match SHA256SUMS is damaged or altered. Get the image set again.

A write failed or the phone stopped answering

  • After a partial install the phone may not start, or it may keep restarting. It can still be installed.
  • Bring it to Fastboot Mode, connect it and press Install again. The install writes everything again from the start.
  • If it fails at the same place twice, try another USB port or cable, without a hub.

It stopped while writing super

  • The bootloader sometimes stops answering after the first part of super. Only a forced restart frees it.
  • The installer then offers to continue in fastbootd. It writes each system partition there, then returns to the bootloader for the last steps.
  • If the page was closed, run the whole install again. If it stops at super again, use the fastbootd steps it offers.

fastbootd does not start or fails

  • Bring the phone to Fastboot Mode and run the whole install again.
  • If fastbootd fails again, return to the stock OS as below, then install again.

Returning to the stock OS

  • Install Fairphone's factory package with Fairphone's instructions.
  • Relock only on the stock OS, and only after the checks in the recovery preflight.

Never do these to fix a failed install

  • Do not lock the bootloader. A locked phone that does not start may not be recoverable.
  • Do not run fastboot -w or fastboot erase. The install writes empty images instead.
  • Do not switch to slot b. It holds no operating system.
  • Do not install firmware older than the phone already runs.

Asking for help

Copy the Log at the end of the installer page into your report. It holds no serial numbers.
